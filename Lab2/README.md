# Lab 2 - Data Types, Variables, Operators, and Basic I/O

This lab demonstrates Python variables, data types, arithmetic operators, string operations, user input, and output.

## Files

- types_and_vars.py - Demonstrates variables, calculations, arithmetic operators, and string operations.
- simple_calculator.py - A basic calculator that performs addition, subtraction, multiplication, and division.
- string_fun.py - Demonstrates string length, uppercase conversion, and string repetition.
